# Group-aware five-fold verification archive

Executed outputs from the post-harmonization subject/group-aware sensitivity analysis. The analysis retained the original 608 development samples and 17,220-gene harmonized matrix but replaced sample-level validation folds with the conservative group-aware assignment supplied as Supplementary Data File D4. No reconstructed subject/source group spans training and validation within a fold.

These files are compact verification outputs; checkpoints and the large generated harmonized matrix are intentionally not committed.
