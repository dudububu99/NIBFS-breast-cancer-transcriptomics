# Start here

1. Create a fresh environment and install `requirements.txt`.
2. Run `python scripts/01_audit_archived_results.py`.
3. Run `python -m pytest -q`.
4. Open `notebooks/NIBFS_REPRODUCIBILITY_WALKTHROUGH.ipynb` for a guided inspection.
5. For a new primary-CV run, provide the required preprocessed expression matrix and fixed STRING ranking, then use `scripts/03_run_primary_cv_from_preprocessed.py`.
6. Before a public GitHub/Zenodo release, choose a license and replace only the explicit repository/DOI placeholders after those identifiers exist.
